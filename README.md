# Rock Paper Scissors Game

## Overview
A menu-driven Python game with randomized computer moves, score tracking, persistent JSON storage, validation and automated tests.

## Features
- Play unlimited rounds
- Win/loss/draw calculation
- Persistent scoreboard
- Reset scoreboard
- Input validation
- Unit tests

## Technologies / Tools
- Python 3
- Standard library only
- JSON file storage where applicable
- unittest for validation tests
- Git/GitHub for version control

## Project Structure
Run `python main.py` from this folder. Run `python -m unittest` to execute tests.

## Installation & Run
1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Open the integrated terminal.
4. Run `python main.py`.
5. For testing, run `python -m unittest`.

## Target Users
Students and casual users learning Python control flow, functions, modules, classes and file handling.

## Academic Scope
The project is designed around the VITyarthi Build Your Own Project requirements: multiple functional modules, clear input/output, workflow, validation, modular implementation, documentation and testing.
